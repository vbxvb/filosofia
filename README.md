# Além da Caverna

Site estático em HTML e CSS sobre a Alegoria da Caverna, de Platão. O projeto tem três páginas conectadas: início, explicação da alegoria (com tabela) e reflexões com o espaço para o vídeo do grupo.

## Como visualizar

Abra `index.html` no navegador ou publique o repositório com GitHub Pages.

## Adicionar o vídeo do grupo

Grave e edite um vídeo de 2 a 5 minutos com todos os integrantes aparecendo. Crie a pasta `videos` na raiz do projeto e coloque nela o arquivo `video-caverna.mp4`. O player já está incorporado em `reflexoes.html` e carregará esse arquivo.

As imagens e fontes são carregadas de serviços externos (Unsplash e Google Fonts), então precisam de conexão com a internet.
